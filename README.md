# 阿金便利贴 · NoteFlow

把待办、随手记和计划贴在电脑桌面。选择顺手的纸张，直接书写、逐项完成，再从日历回看做过的事。

## 1.18.0 功能

- **时间线与周待办**：时间线按一天的时间顺序排列，提供 4 款样式。周待办可切换一周七天，提供 6 款样式，包括一周计划条、七日周计划；另外提供周打卡和月打卡。
- **直接选择样式**：点击新建直接查看便签预览，分为极简日常、手账趣味、时间线、周待办、习惯打卡。自定义便签排在第一，默认白纸空白；酒红分栏笔记不再提供新增入口。
- **清爽的事项行**：鼠标移到事项上，在右侧“⋯”设置优先级、截止提醒、专注和编辑操作。设置后以小色点和小时钟提示，操作按钮不再单独占一行。
- **四象限与截止提醒**：每条待办可设置紧急程度、截止日期和时间。普通清单按四象限排序，同级按截止时间排列；时间线按实际时间排序。默认提前 10 分钟提醒，可调整或关闭。提醒需要应用运行或托盘常驻。
- **随手记**：纯色便笺、横线笔记、商务侧签、深色备忘、磨砂玻璃 5 种纸张。支持自定义纸色、文字色、点缀色和透明度，以及字体、字号、加粗等排版，内容自动保存。
- **按列整理**：框选后可只整理所选便签，保留现有列，或重新分成 2、3、4 列。先预览再应用，支持撤销；便签尺寸和锁定位置保留。
- **完成日历**：选择年份、月份，以统一的圆形计数展示今日、所选月份和所选年份的完成数量。点击统计或日期查看完整事项；年度视图提供各月数量，相关便签可主动呼出。不统计专注时长。
- **语音输入文字**：随手记和待办输入栏可唤起 Windows 系统听写。需要联网和麦克风，首次确认后使用；录音由系统语音面板控制。
- **紧凑控制条**：宽度随内容收紧，收起按钮固定在最右侧；框选、整理、声音和设置放入“更多”。新建便签和随手记统一使用轻铃音效，可关闭声音。

## 日常使用

- **快捷新建**：默认 `Alt + N` 新建随手记，`Alt + D` 新建待办，窗口出现在鼠标附近，可自由移动。快捷键可修改或关闭，占用时会提示。
- **桌面操作**：拖动标题移动，边角调整大小；锁定后保留位置与尺寸。“更多 → 框选便签”支持一起移动，Shift 追加选择，Esc 退出。
- **完成与循环**：完成事项显示进度，全部完成时出现猫爪印章和彩带。点击循环图标重置状态，文字保留，历史完成记录保留；取消误勾会撤回本次记录。
- **番茄钟**：关联具体事项，计时结束后手动确认“完成这一项”。专注记录保留项目、事项和时长，可删除。
- **本地保存**：便签、布局、归档、完成历史和专注记录保存在本机。升级前建议备份；网页预览与桌面安装版的数据不会自动同步。

## 开发与构建

项目使用 React、TypeScript、Vite 和 Tauri。在 Windows 上构建需要 Node.js、Rust MSVC、Microsoft C++ Build Tools、Windows SDK 与 WebView2。

```bash
npm ci
npm run dev          # 网页预览
npm run tauri dev    # 桌面开发
npm run lint         # 类型检查
npm run tauri build  # 构建桌面安装包
```

安装包输出到 `src-tauri/target/release/bundle/nsis/`。详细操作见 [WINDOWS.md](WINDOWS.md)。
